2. Request Flow — Step by Step
Step 1

User Input

Browser sends POST /chat with JSON message

Step 2

IAM Auth

Flask exchanges API Key → Bearer token from IBM Cloud IAM

Step 3

Prompt Build

System prompt + last 6 history turns + user message assembled

Step 4

Granite Call

POST to watsonx.ai with model_id, project_id, parameters

Step 5

Response

Generated text stripped, stored in history, returned as JSON

Step 6

UI Render

Browser appends agent bubble, hides typing indicator

3. Technology Stack
UI

Frontend — HTML5 / CSS3 / Vanilla JS

Single-page chat UI · render_template_string() · Sidebar quick topics · Typing indicator · Auto-resize textarea

BE

Backend — Python 3 · Flask 3.x

Routes: GET / · POST /chat · POST /reset · In-memory conversation_history list · threading.Lock for token safety

AI

LLM — IBM Granite (ibm/granite-4-h-small) on watsonx.ai

Endpoint: eu-de.ml.cloud.ibm.com · greedy decoding · max_new_tokens: 600 · repetition_penalty: 1.1 · stop_sequences: ["User:","Human:"]

AUTH

Auth — IBM Cloud IAM

API Key → Bearer token exchange on every request · grant_type: urn:ibm:params:oauth:grant-type:apikey

PKG

Dependencies — requirements.txt

flask >= 3.0.0 · requests >= 2.31.0 · Runtime: Anaconda Python (C:\Users\nairm\anaconda3\python.exe)
